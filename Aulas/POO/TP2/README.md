# Trabalho Prático 2 - Sistema de E-commerce

## Descrição
Este projeto desenvolve uma **Loja Virtual Simplificada**, implementada em Java com interfaace gráfica utilizando Swing. A aplicação permite que o administrador gerencie o catálogo de produtos e que o cliente consulte os itens disponíveis, montem um carrinho de compras, selecione a forma de pagamento e finalize seus pedidos.

## Funcionalidades
- Herança
- Classes abstratas
- Polimosfismo
- Coleções (contêineres)
- Encapsulamento
- Downcasting
- Tratamento de exceções
- Interface gráfica com Swing

openjdk 21.0.12.1
